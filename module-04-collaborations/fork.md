# Forks

## What is a Fork?

A fork creates your own copy of another person's GitHub repository.

Unlike cloning, a fork exists under your GitHub account.


## Fork Workflow

```
Original Repository
        ↓
Fork Repository
        ↓
Clone Fork
        ↓
Create Branch
        ↓
Commit Changes
        ↓
Push Changes
        ↓
Open Pull Request
```


## Why Fork?

- Contribute to open source
- Experiment safely
- Maintain your own version
