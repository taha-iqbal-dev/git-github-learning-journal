# Pull Requests

## What is a Pull Request?

A Pull Request (PR) is a request to merge changes from one branch into another.

It allows teammates to review code before merging.


## Typical Workflow

```
Create Branch
      ↓
Make Changes
      ↓
Commit Changes
      ↓
Push Branch
      ↓
Open Pull Request
      ↓
Code Review
      ↓
Approve
      ↓
Merge
      ↓
Delete Branch
```


## Commands

```bash
git checkout -b feature-login

git add .

git commit -m "Add login page"

git push origin feature-login
```

Open GitHub

Compare branch

Create Pull Request

Review

Merge

Delete branch


## Why Pull Requests?

- Improve code quality
- Team collaboration
- Easier reviews
- Prevent direct changes to main
- Keep project history clean
