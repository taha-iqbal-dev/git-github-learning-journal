# GitHub Commands

## Show remote repositories

```bash
git remote -v
```

---

## Show detailed remote information

```bash
git remote show origin
```

---

## Display remote URL

```bash
git remote get-url origin
```

---

## Add a remote

```bash
git remote add origin URL
```

---

## Remove a remote

```bash
git remote remove origin
```

---

## Rename a remote

```bash
git remote rename origin upstream
```
